# Healthcare-analysis
1. Project Title / Headline -
   An interactive healthcare analytics platform that helps hospitals track patient data, medical conditions, hospital trends, and doctor performance in real time 
   for better decision-making.

2. Short Description / Purpose -
   This analysis helps hospitals understand patient trends,patient admissions, doctor performance, medical conditions, improve healthcare services, and make better 
   decisions using data.

3. Tech Stack -
   * Power BI Desktop – Main data visualization platform used for report creation and 
     interactive dashboard design.
   * Power Query – Data transformation and Data Cleaning .
   * DAX (Data Analysis Expressions) – Used for calculated measures, key performance indicators (KPIs).
   * File Format – .pbix for development and .png for dashboard previews and exports.

4. Data Source - The dashboard uses data from Hospital Information Systems (HIS), including patient details, admissions, blood type, billing amount, medical conditions, insurance, hospital name , room number  and doctor performance.

5.  Features / Highlights - GOAL OF THE DASHBOARD - This dashboard helps track patient admissions, healthcare trends, and hospital performance in real time.
It supports better decision-making by analyzing medical conditions, doctor performance, and patient data. It also monitors billing and financial performance across hospitals and insurance providers.

Walkthrough of Key Visuals - 
* Monthly Patients by Medical Condition (Multi-Line Chart) - Shows monthly patient trends for major medical conditions like Diabetes, Cancer, Asthma, and Hypertension, obacity, Arthritis.
* Patient Count by Year and Gender (Stacked Bar Chart) - Shows yearly patient admission trends from 2020 to 2024 for male and female patients.
* Patient Count by Blood Type (Donut Chart) - Shows the distribution of patients by different blood groups. It helps in blood bank planning and resource management.
* Top 5 Doctors by Patient Count (Horizontal Bar Chart) - Shows doctors with the highest number of patients.It helps analyze doctor workload and patient handling.

 Insights - Healthcare teams can track patient trends and manage hospital resources like beds, staff, and equipment more efficiently.
It also helps balance doctor workload and improve the quality of patient care.
